# Сергей Дербеко — портфолио

Статический сайт-портфолио на HTML, CSS и JavaScript. Не требует сборки или зависимостей.

## Структура

- `index.html` — содержание и разметка
- `styles.css` — оформление и адаптивная версия
- `script.js` — мобильная навигация и анимации

## Публикация через GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. После завершения публикации GitHub покажет адрес сайта в этом же разделе.

## Добавление проектов

Добавьте карточки проектов в секцию `#projects` в `index.html`. Для каждой работы желательно подготовить название, краткое описание, используемые технологии, изображение и ссылку на исходный код или демо.

## Важно об админ-панели

GitHub Pages обслуживает статические файлы. Пароль, проверяемый в браузерном JavaScript, нельзя считать защитой: его можно извлечь из исходного кода. Поэтому парольная админ-панель не добавлена в публичный фронтенд. Для безопасного управления контентом потребуется серверная авторизация или защищённый внешний сервис. Не помещайте GitHub Personal Access Token в файлы сайта.
